Default owner name

Used on the receipt letterhead for any tenant that doesn't have its own owner name set. If your properties belong to different owners, set the owner name per tenant instead (Tenants tab → edit tenant) — that always overrides this default.

Security

A password screen keeps casual visitors from opening this page. Note: since this is a plain web page with no server, it's a deterrent, not bank-grade security — anyone with real technical skill and access to the device could bypass it. Don't store anything here you'd consider truly sensitive.
